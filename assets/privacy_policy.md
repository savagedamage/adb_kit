## 2. Permissions We Use

When the application runs, it may request the following permissions:
- **android.permission.CAMERA**: use the camera to scan QR codes
- **android.permission.WRITE_EXTERNAL_STORAGE**: save received files to external storage
- **android.permission.INTERNET**: establish internet connections with devices on the local network
- **android.permission.ACCESS_WIFI_STATE**: allow the app to obtain the current Wi-Fi connection state and hotspot information
- **android.permission.CHANGE_WIFI_MULTICAST_STATE**: allow the app to change Wi-Fi multicast state
- **android.permission.ACCESS_NETWORK_STATE**: allow the app to obtain network status information, such as whether the current network connection is available

We use these permissions only to ensure that the application's features work correctly. They do not interfere with normal device operation and are not used to leak private information.
